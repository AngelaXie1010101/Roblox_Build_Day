Roblox Studio basics

Roblox Studio is the free app creators use to build Roblox games.

It runs on Windows and Mac and lets you design 3D worlds, add objects, test your game, and write simple scripts. Build Day starts from zero, so students can join even if they have never coded or opened Studio before.

01

Download

Create or sign in with a Roblox account, open the Roblox Studio setup page, download the installer, then launch Studio.

02

Use

Start with a template, place parts in the 3D workspace, move and resize objects, then press Play to test your game.

03

Code

Use beginner Lua scripts to make things happen, like opening doors, adding points, creating obstacles, or reacting to players.
